# Exemplo Salão Elite (trechos)

Trechos adaptados de um projeto Laravel + Inertia reais. **Sem** segredos, `.env` ou código de produto.

Use para ver como constitution, plan-template e rules ficam em um app com domínio em português.

## Como reaproveitar

1. Copie o plan-template para `.specify/templates/plan-template.md` (ou overrides).
2. Ajuste namespaces (`SalaoElite\`) e comando de teste.
3. Combine com as rules genéricas de [`templates/`](../../templates/).
